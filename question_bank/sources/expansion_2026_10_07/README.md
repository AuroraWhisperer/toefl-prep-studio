# 2026-10-07 造句扩充源稿

`build_sentence.json` 是新增 W451–W750 共 300 道原创造句题的维护来源。造句池由 150 增至 450 题，写作共 750 题；邮件和学术讨论各 150 题。

每条记录的 `question` 只含公开对话、指令、固定片段与乱序词块；`answer` 保存可接受词序和“读懂／解析／下次”三行中文学习解析；`review` 保存难度、考点、材料中实际出现的词汇、理由、答案依据和审阅日期。难度是按固定文字及词块后的实际任务作出的本地判断，不是 ETS 标定。

题面没有正确词序、干扰词标记或答案。117 道新题收录了额外可接受词序，全组共 445 条接受答案；每个答案都须符合原样词块、固定片段、每空一个词块和每个索引最多使用一次。收录的是逐题检查过的常见自然表达，不声称穷尽全部英语词序；后续若发现合理漏收，按[题库维护流程](../../README.md#修改一道题的流程)复核并补充，不修改旧答卷。

2026-10-08 对本组 300 题再次逐题复核，修订 85 题，当前分级为简单 76、适中 217、困难 7；考点、词序、解析及验证细节见[复核报告](../../../docs/question-bank/sentence-review-2026-10-08.md)。该次综合复核未修改的 215 条没有仅为重读而刷新原指纹。

同日后续按用户要求，逐题重读并改写全部 300 题的学习解析，让中文说明直接回答题意、排列原因和检查方法；保持本轮起点的题面、接受答案、考点与难度。对应改动均经内容审阅后更新指纹，见[解析通俗性复核](../../../docs/question-bank/sentence-explanations-2026-10-08.md)。

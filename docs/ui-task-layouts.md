## 真实性边界

- 练习库是本项目原创题，不能称为 ETS 真题；导入的 ETS 试卷属于独立模考题库，见 [题库隔离说明](question-bank/mock-isolation.md)。
- 以上依据支持题型的信息组织，不支持把当前网站宣称为 ETS 机考界面的一比一复刻。原题字段或官方媒体缺失时，应保留限制，而不是为填满空白添加虚构内容。
- 练习模式保留手动重播、脚本、文字转写及反馈回退；这些本地功能与正式作答区须明确区分。转写辅助默认收起，已有转写自动展开；录音不可用或权限拒绝时自动展开并聚焦输入。本次不改变播放次数、录音时限或考试规则。
- 官方场景图／面试官视频未与原创题对应；邮件原题也缺少 To/Subject 字段。没有补造这些素材或字段，也没有制作无功能的 Cut/Paste 工具栏。因此采用的是有证据的题面布局，而非完整考场软件的逐像素复刻。
- 大屏适配使用已有题目和控制区；选项保持原顺序与单选行为，不做营销式大卡片网格，不引入额外题目、答案提示或模拟人物。

## 本轮验证

- `node --check`：应用脚本和本次改动的三个浏览器测试／辅助文件通过。
- 十二种练习题型在 2560×1440、2048×1152（125% 等效）、1707×960（150% 等效）、1280×800 和 1000×800 桌面窗口下通过布局及交互检查。检查包括原文保留、词块位置、字数位置、默认折叠、键盘焦点和麦克风不可用／拒绝后的文字回退。
- 全量浏览器回归首跑 91/92 通过；音频用例 `conversation uses stable distinct voices, ordered clips and natural turn gaps` 的 `plays` 与 `created` Blob 顺序断言失败。未改音频实现或放宽断言；该用例隔离后连续三次通过。不要把首跑报告写成全绿。
- 实际浏览器手动验证了文章区域的 Home/End 滚动，题干的文档位置保持不变；默认题面截图位于 `artifacts/official-all-task-screens-tests/`。
- 使用独立服务和临时数据，未重启用户服务；本轮没有验证真实麦克风质量或在线语音服务质量。

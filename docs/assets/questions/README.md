# README 题型截图

供根目录中英文 README 共用。2026-09-29 从本项目的原创专项练习界面截取，每种题型一张；不含 ETS 模考材料或个人记录。

## 更新约定

- 使用独立服务和 `TOEFL_DATA_DIR`，从正常练习界面进入题目，不修改题干、选项或应用样式来制作截图。
- 仅截取题目内容：阅读保留材料与一道题，听力保留题干与选项，造句保留词块与空位，邮件和讨论保留完整要求，口语展开练习脚本并保留播放、录音控件。
- 去掉导航、计时、交卷栏及空白写作编辑框。完整保留文字、选项边框和填空控件；学术文章应通过增加桌面窗口高度完整显示，避免截在半句话中间。
- 使用 2× 像素密度的 PNG，四周各加 15 CSS 像素白边及 1 CSS 像素细边框，保持原始比例。只做无损 PNG 压缩。
- README 使用单栏居中布局，阅读默认展开，其他科目折叠。固定显示宽度见下表，高度随图片比例变化；每张图链接到自身以便查看原图，并提供中英文替代文本。
- 截图更新时同时检查两份 README 的图片引用、显示宽度、展开状态和放大链接。保持整组体积约 1.4 MB，避免直接放入整屏截图。

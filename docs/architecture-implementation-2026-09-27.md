## 关键实现与职责

- [只读归档校验](../backend/archive_io.py)：按当前读取操作验证结构，返回原始对象，不填默认值或改写文件。损坏返回 409，读取失败返回 503。
- [进程内读取索引](../backend/archive_index.py)：元数据扫描、按文件投影、成功写入失效、删除与换根重建；缓存读取失败仍报错，不返回伪造空结果。
- [历史模块](../backend/history.py)：继续拥有成功提交归档、列表摘要、材料计数与概率重置；摘要和材料投影不另行持久化。
- [模考模块](../backend/mock_exam.py)：继续拥有会话、时序和整卷复盘；列表使用只读快照，路由与历史共享完成复盘业务能力。

## G：合成规模测量

方法：每个规模各生成 N 份 50 题阅读练习归档和 N 份已完成、空答案的 97 题模考会话；不读取用户答题正文。最大数据总量 802,750,000 字节。所有数据写入本次拥有的系统临时目录并在结束后删除。

# v1.3.0 — 补词译文、复盘改进与可靠性修复

发布日期：2026-10-07。基于 v1.2.0，继续面向 Windows 桌面浏览器提供本地练习、综合测验、模考与历史复盘。

## 本次更新

- **全部 270 篇原创补词新增中文参考译文。** 交卷后在英文下方显示，专项、整科、已完成综合测验和历史复盘均可使用。译文保存在本地，运行时无需翻译服务；仅在完整英文与保存的来源一致时显示，防止新译文误配旧答卷。作答期间不返回译文，已有答卷和评分不改写。见[译文维护说明](../../question_bank/README.md#补词整篇译文)。
- **复盘显示题目难度，改善造句核对。** 各题型及综合测验显示答卷保存的难度，缺失或未分级的题目（包括 ETS 模考）明确标注「待分级」。造句在右侧并列呈现自己的词块与正确句子，用颜色和文字提示空格位置是否匹配，并支持结果导航；左侧保留成绩与解析。
- **调整复盘布局与交互。** 优化桌面双栏、材料标题、段落缩进与间距；补词复盘在宽窗口下通过滚轮统一滚动答案栏，保留减少动态效果设置和窄桌面窗口回退。解析展开状态随题目切换保留，减少重复内容，作答与复盘共用材料渲染，模考交卷与历史共用复盘展示。界面约定见[设计说明](../../DESIGN.md)。
- **修复页面切换和模考恢复竞态。** 离开正在取题的练习后取消请求，慢响应不会重新打开旧页面；模考与综合测验恢复经过共享导航队列。离开模考结果加载页后，旧结果或错误不会覆盖新会话；交卷冲突后同步失败会保留答案、显示原因并提示重试。见[导航与模块说明](../technical/architecture.md)。
- **提高交卷重试与文字评分一致性。** 相同提交 ID 和内容优先返回原归档结果，不受后续固定题组更新影响；不同内容仍拒绝重复使用同一 ID。文字比对和字数统计统一处理直撇号与弯撇号，避免缩写、所有格因字符样式被拆词或扣分。历史成绩不追溯重算。见[接口说明](../technical/api.md)。
- **更新前端缓存与导入校验。** 页面和前端资源使用 `Cache-Control: no-store`，普通刷新可加载当前文件。模考导入先解析、校验并编码全部图片，再写入该卷产物；仅重建题面时先检查原 PDF 指纹，避免新题面混用旧答案。题库生成加强答案依据与审阅日期校验，校验失败时保留已有产物。见[开发指南](../technical/development.md)和[题库维护流程](../../question_bank/README.md)。

## 升级与使用

更新源码时保留自己的 `artifacts/` 或自定义 `TOEFL_DATA_DIR`。结束当前练习后，从旧托盘「退出服务」或关闭旧命令行服务，再双击根目录的 `TOEFL Prep Studio.cmd`，载入新版后端与译文。首次启用前端缓存策略时，在原页面按一次 `Ctrl + F5`；此后前端更新普通刷新即可。无需重新生成原创题库。

历史答卷、提交时的评分、反馈和录音继续保留。ETS 模考试卷仍需本地另行导入，源码包不包含官方材料。译文和难度标签属于本地学习参考；开放写作与访谈继续待人工复核，复述文字匹配不评估发音或流利度。

## English

All **270 original cloze passages** now provide locally stored Chinese reference translations after submission, including completed comprehensive tests and saved review. Translations are matched against the intact English passage reconstructed from saved reference words. Existing responses and grades remain intact, and practice payloads contain no translations.

Review displays each question's saved difficulty, explicitly marks unclassified items, and shows sentence tile positions alongside the correct sentence. Desktop review layouts, scrolling, explanation toggles, and shared material rendering are improved.

Navigation fixes prevent delayed requests from reopening old practice pages or overwriting newer mock sessions. Identical submission retries return the archived result before checking the current question set. Text matching and word counts treat straight and curly apostrophes consistently. Frontend pages and assets avoid stale caches; mock imports validate and render before writing, and structured-only rebuilds reject changed source PDFs. Question-bank generation now requires answer evidence and review dates.

Keep your personal data, finish practice, stop the previous service, and restart with `TOEFL Prep Studio.cmd`. Use `Ctrl + F5` once to clear the previous frontend cache policy. No original-bank rebuild is needed; ETS materials remain a separate local import.

Release checks: **566 Python tests and 247 browser tests passed**, along with formatting, JavaScript syntax, local documentation path, and Git diff checks. All seven checked page/API routes returned HTTP 200 with API version 1.3.0. Desktop scaling was simulated in the browser; real microphones and online speech-service quality were not verified. Automated translation checks establish coverage and source matching, not semantic accuracy.

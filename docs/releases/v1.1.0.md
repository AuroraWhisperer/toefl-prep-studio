# v1.1.0 — 题库扩充、人工复核与复盘体验

发布日期：2026-09-30。基于 v1.0.0，继续面向 Windows 桌面浏览器提供本地练习、综合测验、模考与历史复盘。

## 本次更新

- **原创题库从 2,115 题增至 3,615 题。** 阅读增加 795 题，达到 1,590 题；听力增加 705 题，达到 1,410 题，七个题型分别翻倍。写作 450 题、口语 165 题，仍覆盖全部 12 种题型。扩充保留完整材料组，提交接口支持新增的四位数题号。见[扩充明细](../question-bank/receptive-expansion-2026-09-30.md)。
- **修订题目、答案和学习解析。** 逐题复核全部 3,000 道阅读与听力题，修正科学表述、干扰项、填词接受答案及难度标签，增加不同学术题材；后续复查口语文本并逐篇复核全部 450 道写作，补收 17 个造句变体，修正范文与中文解析。三行解析继续按「读懂／解析／下次」说明证据、判断和方法。见[阅读听力修订](../question-bank/receptive-repair-2026-09-30.md)与[口语写作复核](../question-bank/productive-repair-2026-09-30.md)。
- **开放题统一标记“待人工复核”。** 普通练习的邮件、学术讨论和访谈不再依据范文关键词、字数和句号数量给数值分或正误结论。保留字数、重复措辞提示、参考内容及解析，开放题不进入分数或正确率；含开放题的科目及本次总览不再换算数字等级。纯开放题结果和历史列表显示待复核，混合练习标明自动核对部分。
- **保护既有成绩与提交记录。** 同一提交 ID 和同一内容的重试返回原归档结果，避免新版评分替换历史反馈；原答卷、分数、反馈与录音继续保留。
- **完善综合测验组卷。** 多材料阶段在题池允许时保留非简单内容，避免偶然组成全简单阶段，同时保留完整材料和同轮不重复规则。
- **改善桌面复盘排版。** 解析、音频脚本、个人答案及参考内容采用更易读的正文字号和行距，明确 Windows 中文字体回退；长写作题干使用普通段落，开放题范例使用正文颜色，结果说明单独成行。
- **整理文档和开发产物。** 中英文 README 同步题量、评分边界与版本入口；已完成的截图、测试输出和缓存移入本机 `tmp/`，更新目录索引，临时文件不随 GitHub 源码分发。

## 升级与使用

下载本版本源码后，双击根目录的 `TOEFL Prep Studio.cmd` 启动。已有用户更新时保留自己的 `artifacts/` 或自定义 `TOEFL_DATA_DIR`，关闭旧服务后重新启动，使新版题库与评分逻辑生效。无需重新生成题库。

历史记录保留提交时的评分。新提交的开放写作与访谈需人工复核；复述仍只比对转写文字。练习分不等于官方 TOEFL 成绩，也不评估发音或流利度。ETS 模考材料继续由用户在本地合法导入，源码包不包含这些材料。

## English

The original bank grows from 2,115 to **3,615 items**, with every Reading and Listening task pool doubled. This release includes a review of all 3,000 receptive items, further speaking and writing revisions, and 17 additional accepted sentence-building variants.

Emails, academic discussions, and interviews now require **manual review** in ordinary practice. They retain word-count and repetition hints but receive no numeric grade or correctness judgment and are excluded from score denominators. Existing archived grades remain intact, including on identical submission retries.

Comprehensive tests retain some non-easy content in stages with multiple materials when the pool permits it. Review text, writing prompts, transcripts, and reference examples use clearer desktop typography. Both READMEs and the local artifact indexes are updated.

Restart the local service after updating, and retain your personal `artifacts/` or `TOEFL_DATA_DIR`. ETS mock materials remain a separate local import. Practice results are not official TOEFL scores.

Release checks: **506 Python tests and 212 browser tests passed**, along with formatting, JavaScript syntax, and Git diff checks. Audio automation uses test doubles and does not validate real microphone or online speech-service quality.

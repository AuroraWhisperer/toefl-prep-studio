# v1.2.0 — 题库扩充、托盘启动与新托福指南

发布日期：2026-10-05。基于 v1.1.0，继续面向 Windows 桌面浏览器提供本地练习、综合测验、模考与历史复盘。

## 本次更新

- **原创题库从 3,615 题增至 5,745 题。** 新增 180 篇补词、30 组听后复述和 30 组访谈，共 2,130 个小题。三个题型分别达到 270 篇／2,700 空、45 组／315 句、45 组／180 问，均为扩充前的三倍。四科题量为阅读 3,390、听力 1,410、口语 495、写作 450；固定整科练习题量不变。见[扩充与验证报告](../question-bank/cloze-speaking-expansion-2026-10-05.md)。
- **修订难度、题目设计与学习解析。** 扩充前复核原有 3,615 题，修订其中 701 题，涵盖补词语法目标、材料与干扰项、合法造句变体、复述句子及三行中文解析。难度按可见提示、结构、语境和实际作答负担判断，不以生僻词或范文复杂度替代难度，也不强制各档比例。保留题号和材料组；开放写作与访谈继续待人工复核。见[修订报告](../question-bank/content-repair-2026-10-05.md)。
- **新增 Windows 系统托盘启动。** 双击启动器完成环境检查后关闭终端，在托盘运行服务并打开页面；托盘菜单可重新打开页面、查看日志或退出服务。重复启动复用已有服务，关闭网页不会停止服务。支持高 DPI 菜单及日志轮转。命令行启动仍可用于排错。见[启动与环境说明](../technical/development.md#环境与启动)。
- **新增「2026 新托福指南」。** 首页入口打开独立指南页，按四科介绍 12 种题型、参考材料数与题量，并区分正式考试说明和本应用练习用时。支持科目展开、键盘操作、浏览器前进／后退与刷新；附来源及未固定题量的说明。见[指南核查记录](../toefl-2026-guide.md)。
- **改善阅读作答。** 补词展示当前文章标题，输入一个词的最后一个缺失字母后自动移到同篇下一词；词义题高亮原文目标词或短语，并在进入题目时定位对应段落，选择答案时保留手动滚动位置。普通练习、整科练习和综合测验共用这些行为。
- **调整桌面布局与操作。** 练习设置显示各题型题库总量，区分题池容量与本轮题量；统一返回按钮，精简重复提示，调整首页、练习、复盘、模考及综合测验的颜色、宽度与间距，兼顾桌面窗口和 125%／150% 等效缩放。
- **加强归档校验与综合测验恢复。** 缺少参考答案或反馈遗漏、重复的完整归档会报告可定位的错误；读取不会静默改写旧记录。综合测验录音补传及历史清理先恢复已完成会话的状态，使完成归档与后续操作保持一致。见[历史归档规则](../../specs/history-management.md#archive-diagnostics-and-recovery)。

## 发布验证

- Python 全量回归：**545 项通过**，包含题库重建一致性、审阅指纹、评分与历史、归档诊断、综合测验恢复和启动器测试；保留两条现有测试依赖弃用提示。
- 浏览器全量回归：**228 项通过**，覆盖练习、综合测验、模考、指南、阅读定位、键鼠操作、录音恢复及桌面缩放。
- Prettier、Ruff 格式检查、全部改动 JavaScript 的语法检查及 Git 差异检查通过；两份 README 与本说明的 **103 个本地路径引用**核对通过。
- 隔离服务的首页、指南、阅读设置、历史、综合测验、模考与 OpenAPI 路由均返回 HTTP 200；API 版本为 **1.2.0**。查看了指南及补词页面在 125%／150% 等效桌面缩放下的截图。

显示缩放采用浏览器视口和设备像素比模拟，未改变 Windows 原生缩放；本轮未人工操作原生托盘菜单。音频自动化使用模拟设备和测试音频，不验证真实麦克风或在线语音服务质量。测试使用隔离数据，未重启用户服务。

## 升级与使用

更新源码时保留自己的 `artifacts/` 或自定义 `TOEFL_DATA_DIR`。结束当前练习后，从旧托盘「退出服务」或关闭旧命令行服务，再双击根目录的 `TOEFL Prep Studio.cmd`；启动器会安装新增的 Windows 托盘依赖并载入新版题库。首次安装或补装依赖需要联网，无需重新生成题库。

历史答卷、提交时的评分、反馈和录音继续保留。ETS 模考试卷仍需在本地另行导入，源码包不包含官方材料。难度标签属于本地内容判断，练习结果不是官方 TOEFL 成绩；开放写作与访谈需人工复核，复述文字匹配不评估发音或流利度。

## English

The original bank grows from 3,615 to **5,745 items**, adding 180 cloze passages, 30 repetition groups, and 30 interview groups. Each of these three pools is now three times its previous size. Fixed whole-section practice counts remain unchanged. A preceding review revised 701 existing items, improving grammar coverage, difficulty judgments, distractors, accepted sentence variants, repetition scripts, and learner explanations while preserving IDs and material groups.

The Windows launcher now runs in the **system tray**, with commands to reopen the page, view rotating logs, and stop its service. A new **2026 TOEFL guide** explains all 12 task types and distinguishes exam reference information from local practice timings.

Reading practice advances between completed cloze words and highlights vocabulary targets in their source paragraphs without resetting manual scrolling while answering. Setup displays task-pool totals; desktop layouts and navigation are refined. Archive validation detects missing or duplicate feedback, and comprehensive-test recording uploads and history cleanup recover completed-session state before proceeding.

Keep your personal `artifacts/` or `TOEFL_DATA_DIR`, stop the previous service after finishing practice, and run `TOEFL Prep Studio.cmd` to install the new Windows dependencies and load the updated bank. Existing archived responses and grades remain intact. ETS mock materials remain a separate local import; open writing and interviews still require manual review.

Release checks: **545 Python tests and 228 browser tests passed**, along with formatting, JavaScript syntax, local documentation path, and Git diff checks. All seven checked page/API routes returned HTTP 200 with API version 1.2.0. Desktop scaling was simulated in the browser; native tray menus, real microphones, and online speech-service quality were not manually verified in this release pass.

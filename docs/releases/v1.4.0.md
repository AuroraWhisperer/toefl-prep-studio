# v1.4.0 — 语法与搭配、造句扩充与听力学习支持

发布日期：2026-10-09。基于 v1.3.0，新增学习参考与练习内容，沿用 Windows 桌面浏览器中的本地练习、综合测验、模考和历史复盘。此次为兼容性功能更新，版本由 1.3.0 升至 1.4.0。

## 本次更新

- **新增「语法与搭配」学习页。** 首页右上角可进入独立的 `/foundations` 页面，查阅 24 个主题、400 个知识点和 453 组双语例句，覆盖托福语法、核心搭配和校园及学术场景。支持分类、中英关键词搜索、折叠阅读、键盘操作和前进后退；内容保存在本地，不创建练习或写入答题历史。见[学习页说明](../grammar-and-collocations.md)。
- **造句题由 150 扩至 450 题，原创题库达到 6,045 题。** 新增 W451–W750 共 300 题，覆盖陈述与疑问语序、从句、时态与被动、非谓语、比较和条件关系。写作题库共 750 题；专项仍按原有题量练习，整科仍抽取 10 道造句题。见[扩充报告](../question-bank/sentence-expansion-2026-10-07.md)。
- **复核新增造句题的合理词序、难度与解析。** 后续复核修订 85 题，补收 17 个自然词序，调整 29 题难度，并重写全部 300 道新题的中文解析。每题按「读懂／解析／下次」说明题意、排列依据和检查步骤；新增题池共保存 445 条接受答案，遵守固定文字和词块约束。见[逐题复核](../question-bank/sentence-review-2026-10-08.md)与[解析改写](../question-bank/sentence-explanations-2026-10-08.md)。
- **全部 510 道原创听答题新增中文原句译文。** 交卷后、已完成综合测验和历史复盘在英文脚本下显示译文；仅在保存的英文原句匹配时叠加显示，作答取题接口不提供译文。听答题脚本入口改为「查看原文」，简化音频区域文案；旧答卷、成绩和录音保持原样。见[译文维护](../../question_bank/README.md#听答题原句译文)与[接口说明](../technical/api.md)。
- **改善原创听力解析。** 逐题复核 1,410 道原创听力，重写其中 1,251 道解析，保留已经讲清的 159 道。用完整中文说明关键原话、正确项与三个干扰项的区别，纠正具体误读，并明确标记现有歧义，不通过改分掩盖题目限制。维护报告另记录本机 170 道模考听力补充笔记的修订；这些本地补充文件不随 GitHub 源码发布。见[听力解析报告](../question-bank/listening-explanations-2026-10-09.md)。
- **同步指南与维护资料。** 更新中英文 README、题库统计与审阅目录、考试指南、页面布局及本机开发产物索引；扩充取题和提交数量上限，保持题面与服务端答案分离。

## 升级与使用

更新源码时保留自己的 `artifacts/` 或自定义 `TOEFL_DATA_DIR`。结束当前练习后，从旧托盘「退出服务」或关闭旧命令行服务，再双击根目录的 `TOEFL Prep Studio.cmd`，载入新版后端、题库、解析和译文；随后刷新页面。无需重新生成原创题库，也无需迁移历史记录。

语法笔记、中文解析、译文与难度均为本地学习参考，非 ETS 官方解析或难度标定。有限的造句答案列表不保证穷尽所有自然表达；开放写作与访谈继续待人工复核，复述文字匹配不评价发音或流利度。ETS 模考试卷及其本地补充材料仍需另行导入或维护，源码包不包含这些材料。

## English

The new **Grammar and Collocations** page provides **24 topics, 400 learning notes, and 453 bilingual examples**, with category filters, Chinese/English search, expandable notes, keyboard navigation, and browser history support. The page works from local content and does not create practice sessions.

**Build a Sentence grows from 150 to 450 items**, bringing the original bank to **6,045 items**. The 300 new items cover varied sentence structures; follow-up review refines difficulty, accepts 17 additional natural word orders, and rewrites all new sentence explanations in plain Chinese. The new pool contains 445 accepted answers, checked against each item's fixed text and tiles.

All **510 original Listen and Choose a Response prompts** now show locally stored Chinese translations after submission, in completed comprehensive tests, and in saved review. Translations match the archived English script and are excluded from practice payloads. Review of all **1,410 original listening items** rewrites 1,251 explanations and retains 159 that already explain the evidence and alternatives. Existing ambiguity is stated explicitly. Locally revised supplements for 170 mock listening items are documented but are not distributed in this release.

Keep personal data, finish practice, stop the previous service, restart with `TOEFL Prep Studio.cmd`, and refresh the page. No original-bank rebuild or history migration is needed. Learning content and difficulty labels are locally authored references, not official ETS explanations or calibrated difficulty ratings.

Validation: **591 Python tests passed**. The complete browser run covered **268 tests**, with 266 passing initially; two stale expectations were updated for the expanded sentence bank and the added Chinese transcript paragraph. All **5 targeted follow-up tests passed**, covering both corrected cases and translation review at three desktop scales. Formatting, JavaScript syntax, documentation paths, mock isolation, and seven page/API routes also passed. Desktop scaling used browser simulation; real microphones and online speech-service quality were not verified.

# Project Cleanup Implementation Plan

**Goal:** 核查全项目命名、引用和冗余，在保留功能及数据合同的前提下直接整理。

**Architecture:** 保留 FastAPI 与原生前端的现有职责边界。依据静态引用、字符串路径、事件回调、运行入口和现有测试决定改动；一次性脚本移入根目录 `tmp/`，历史证据和用户数据分别保留。

**Tech Stack:** Python / FastAPI / pytest；原生 HTML、CSS、JavaScript；Playwright。

## Global Constraints

- 不增加新功能，不进行与本任务无关的大规模重构。
- 仅重命名确实不合理、过时或与职责不符的名称，并同步所有现行引用。
- 不因静态扫描未发现调用而删除路由、回调、动态字段或兼容入口。
- 不修改题面、答案、审阅指纹和用户历史；测试使用隔离数据。
- 临时／废弃文件只移入 `tmp/`，由用户最后删除。
- 本次按用户要求直接在当前会话执行；不提交版本，不等待执行方式确认。

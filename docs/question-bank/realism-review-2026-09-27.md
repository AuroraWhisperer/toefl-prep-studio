# 托福题库真实性复核 — 2026-09-27

## 结论

**现有原创题库适合作为 2026 新版托福专项练习，但还不能称为与真实考试难度等值的仿真题库。** 十二种题型的大框架基本正确；主要问题不是沿用了旧版考试，而是部分题型的材料负荷、题目变式和干扰项设计失衡。某些任务偏简化，另一些任务反而加难，不能统一概括为“题库太简单”。

五套 ETS 官方练习的内容来源比原创题库更可靠，但它们是公开的纸面适配样卷，不是泄露真题、完整在线自适应考试，或可直接预测官方分数的等值试卷。本地导入、语音和评分实现仍有独立局限。

本次只新增这份报告和 `tmp/artifacts-2026-09-28/qa/question-bank-realism-2026-09-27/` 审查证据。**没有改题目、答案、难度标签、审阅指纹、应用代码或用户学习历史，也没有重启服务。**

## 主要发现及处理建议

### 1. 主观分数不能用于判断“是否达到真实托福水平”

`backend/exam_service.py` 的复述评分以转写文本相似度为核心；邮件、讨论及面试按字数、关键词命中和极简单的句子结构累加得分。ETS 的对应评分指南则关注沟通目的完成、展开、语言准确性与范围，以及口语清晰度、流利度等。

本次直接调用现有 `score_one`，未提交到历史：给 **W21** 输入重复34次的三个主题关键词，加上一个普通短句，总计106个空格分词，得到 **5.0/5.0**，反馈还声称回答切题。这只是一个评分反例，不是修改过的题目或考生真实答案。

应用已披露这是练习原始分和启发式反馈，因此问题不是“隐瞒官方评分”，而是即使题目改得更好，该分数仍不能支持难度校准或成绩预测。优先把真实训练判断建立在录音/文本复盘及官方评分指南上，不要通过增加关键词来“修好”这个评分器。

### 2. 听答题存在较明显的长度线索

| 指标 | 原创听答题 | 五套官方样卷听答题 |
|---|---:|---:|
| 题数 | 85 | 80 |
| 正确项是单独最长选项 | 40（47.1%） | 13（16.3%） |
| 正确项最长，含并列 | 65（76.5%） | 28（35.0%） |

这是计词统计，不等于考生实际猜题正确率；但差距足以提示无关线索风险。抽查 **L49、L60、L75、L90**，有些干扰项只是借用同一个词却明显跑题。短回应的简单题可以考基本辨别，官方也有明显不合语境的选项；问题是这种写法与长度优势组合得过多。**L110** 则已有较好的条件、承诺程度和语用误读设计，应保留并作为改写方向。

建议优先逐题审阅这些题，而不是机械把选项裁成一样长：控制信息量，增加语境相关但在时态、角色、条件、意图或行动上不成立的干扰项；仍须保证唯一最佳答案。

### 3. 听力负荷偏短，复述负荷却偏长

| 材料 | 原创：最短 / 中位 / 最长 | 官方公开样卷：最短 / 中位 / 最长 |
|---|---|---|
| 对话 | 50 / 57 / 98（25段） | 49 / 80 / 94（15段） |
| 公告 | 69 / 73 / 79（20段） | 32 / 68 / 83（10段） |
| 学术讲座 | 141 / 149 / 174（15段） | 187 / 205 / 222（10段） |
| 每组复述最后一句 | 20 / 23 / 26（5组） | 14 / 15 / 17（5组） |

原创讲座比该样本的中位数少约27%的词；阅读式概括比较紧凑，较少训练在更长信息流中保持主线、处理例子和回指。建议保留短材料作为基础练习，再补充较长且自然展开的讲座，而不是为凑词数加无用填充。**不能把“少于187词”当作违规：官方概览允许约100–250词。**

复述 **S07、S18、S25、S32、S39** 的末句均比这五套公开样卷末句长。句长不是唯一难度因素，但在相同12秒预算下，20–26词的末句增加了记忆与输出负担。可保留为进阶挑战，仿真任务另对齐官方样本的句法、音节和节奏；不应宣布真实考试绝不会超过17词。

### 4. 造句不是格式没做对，而是句型覆盖失衡

原创50题的标准答案只有 **4/50** 是以问号结尾的问句：W31、W36、W56、W69。五套官方样卷为 **28/50**，包括一般疑问、特殊疑问、礼貌询问和嵌套询问信息结构。该比例不应照搬为正式考试硬性配比，但本库偏陈述句的方向很明显。

目前已经有25题固定文字、26题多余词块，不能沿用旧审查结论说这些变式尚未实现。建议后续扩充/修订时补充直接疑问、疑问词+助动词、主语疑问和嵌入疑问之间的区别，并保持自然的对话语境，不是单纯堆倒装或复杂从句。

### 5. 学术讨论与邮件题面过于简略

例如 **W21、W121**：教授提出一个简短问题，两名学生各有一句概括性立场。官方样卷会提供更完整的课程/话题背景及学生论述，要求在已有观点之上作出贡献。现有短题仍能练习组织与论证，但读题、提取前人观点、区分重复与补充的负担明显较低。

邮件 **W11、W12、W101** 的沟通目标基本合理，但常将背景与全部要求压缩成一两句。后续应提供自然情境、收件人/关系、清楚的沟通要点及适当的收件人/主题提示。官方公开样卷经常列出三个要点；这是可参照的设计，不是本报告宣布所有正式题永久固定三点。

不要把写作题“难化”为需要专业知识或冷僻论题。完整任务、合理语域与有内容的上下文比更生僻的话题重要。

### 6. 学术阅读有一项明确的覆盖缺口

原创学术阅读50题中没有句子插入题。官方样卷存在四个实例：Test 1 Reading Module 2 Q20、Test 2 Reading Module 2 Q20、Test 4 Reading Module 2 Q20、Test 5 Reading Module 1 Q20。这属于衔接、指代与篇章推进能力，不等同于已有的“作者为什么提到某例子”。

其余阅读不应被整体否定。例如 **R221–R225** 把冰川前缘移动、总体冰量变化、多方法测量和短期异常区分开，材料内提供理解所需信息；**R251–R253** 考查付款、提交表格、提前布展条件，已有真实信息整合负担。建议保留这些设计，补齐缺失变式。

## 模考和音频的额外注意事项

- 正式阅读/听力有自适应机制；本项目整科固定卷与顺序播放的纸卷导入不是该机制。不能把练习得分率直接线性换算成官方水平。官方纸卷题量比官网基准少，也不自动说明导入漏题。
- **TTS本身不是不真实的证据。** ETS 2026 specifications 明确提及AI生成音频和部分真人声音。当前应用也已经有美/英/澳、男女声配置；未验证的是韵律、语速、停顿、语用重音及与目标难度的对应关系。本次未试听真实联网音频，也未测试麦克风。
- 对 **ETS Test 5 Listening Module 2 Q9–10** 发现可复现的标签问题：源脚本使用 `(M-Can)` / `(W-Br)`，当前 `frontend/audio-cache.js` 的 `PromptSpeech.parseTurns` 返回 **1段、空说话人**，不能按两个角色拆分。已直接调用纯解析函数验证；可能影响双人音色与标签朗读，实际合成效果仍需试听。没有擅自修改导入器或前端。
- `docs/question-bank/audit.md` 及其生成源 `scripts/question_bank_review.py` 仍保留“造句没有固定片段和多余词块”的旧说明，与当前50题数据及 `sentence-format.md` 不一致。`PRODUCT.md` 的“没有ETS题目”措辞也没有完整反映独立模考库。这些文档应后续单独纠正，不应因此误判当前实现。

## 建议修订顺序

1. **先停止用主观练习分判断真实水平**：保留其提示用途，依据官方rubric复盘。若需要更可信评分，应作为独立需求实施和验证。
2. **优先修订原创听答题与补齐造句问句**：消除可猜长度线索，增加同语境干扰项和常见问句结构。
3. **补充较长听力和完整写作题面**：保留基础短材料，不把全库一律加难。
4. **加入阅读句子插入，区分标准复述与挑战复述**：扩展考点覆盖而非仅增加题量。
5. **修正模考特殊标签与过时审查文案**：针对性回归后再宣布修复，不批量刷新内容指纹。

原创题库现有195道简单、378道适中、132道困难只是本项目的内容分级，没有考生试测、题目区分度、错误选项选择率或能力等值数据。本次不提供虚构的“真实性百分比”、CEFR逐题标定或可预测官方分数。

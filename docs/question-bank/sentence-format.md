# 造句题：官方格式核对与本地实现

核对日期：2026-09-26。截图仅作用户界面参考，不把第三方截图当成官方规则或题源。

## 官方依据

- [ETS 写作题型说明](https://www.ets.org/toefl/test-takers/ibt/about/content/writing.html)：Build a Sentence 要求排列单词或词组，组成完整、符合语法的陈述句或疑问句。核对时 HTTP 200。
- [ETS Practice Test 1](https://www.cn.ets.org/content/dam/ets-org/pdfs/toefl/toefl-ibt-teachers-resources-practice-test-1.pdf)，印刷页 26–27（PDF 页 27–28）：第 1 题 6 个空、7 个词块，额外词为 `does`；第 2 题 7 个空、7 个词块。因此不能要求每题都用完词库。第 1、2 题没有预填词；第 3 题预填 `I am`，第 4 题预填 `My`，第 5 题在句中固定 `Sally`。在线 PDF 返回 HTTP 200，SHA-256 与项目原卷一致。
- [ETS Practice Test 2](https://www.cn.ets.org/content/dam/ets-org/pdfs/toefl/toefl-ibt-teachers-resources-practice-test-2.pdf)，印刷页 28（PDF 页 29）：第 1 题句尾固定 `music.`；第 2 题句首固定 `I did not`。可见固定内容不限于句首，也不限于一两个单词。该例核对项目保存的官方原卷。

结论：题面给出对话语境、若干横线、可能存在的固定词和句末标点；每空放一个词块，词块可以含多个单词。样卷同时存在词块数量等于空位数、以及多一个词块的题目。这里没有据此断言未来每道正式考题的固定词数或干扰词数上限。

## 本项目实现

- 原创练习 50 题保留题号、对话语境、标准答案和已接受变体；题型格式调整，不把 ETS 原题混入原创练习池。
- `question_bank/sources/sentence_answers.py` 的 `FRAMES` 是新增题面源：花括号标记一个完整词块，其余文字固定；元组第二项可指定一个多余词块。是否给固定词、给几个词块是本地命题设计，不是官方统计分布。
- 生成器仅公开打乱的 `word_bank`、不含答案的 `template_parts` 与指令，不返回正确顺序或干扰词标签。每个既有可接受答案都经过组装验证。
- 作答使用横线而非自由文本框：点击／键盘选择空位和词块、拖动换位、点击撤回、清空；固定词不能编辑。重复文字以不同词块索引区分，同一索引不得重复使用。填满后可以保留未用词块。
- 切题后保留词块位置；服务器继续接收完整句子并判分。部分答案保留缺口，清空后不把固定词单独计为已答。复盘保留原题横线与词库；旧历史无新字段时保持旧展示。
- 模考已经使用官方导入的词块与固定片段，本次只将编号虚线框改为横线；不更改原卷数据、顺序持久化或阶段计时。
- 已启动的服务可能缓存旧题库。新前端兼容旧题面的全词空位，但需要用户重启本地服务再刷新页面，才能加载完整的新题面。不会为这次验证重启用户的服务。

## 验证

`tests/test_sentence_frames.py` 验证所有已接受答案均能以固定片段和不可重复的词块组装；覆盖无固定词、句首／句中／句尾固定词、无干扰词／有干扰词、词组和重复文字。`tests/browser_sentence.test.cjs` 验证实际键盘鼠标交互、导航、清空及服务端判分；桌面显示与模考复用已有浏览器回归套件。只对本次逐题复核的 50 题更新内容指纹，未改变其余题目的审阅记录。

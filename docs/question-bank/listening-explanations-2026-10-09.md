# 全部听力解析逐项改写

这轮修改解决听力解析过于压缩的问题：学习者需要知道原话在说什么、正确回答为什么接得上，以及另外三个选项分别为什么不合适，不能只看到“扩大覆盖”“维度不同”等结论。

## 范围与写法

| 内容 | 小题数 | 核对单位 |
| --- | ---: | --- |
| 原创听答题 | 510 | 每句音频与四个回复 |
| 原创对话 | 300 | 150 段完整对话及对应题目 |
| 原创通知 | 240 | 120 则完整通知及对应题目 |
| 原创学术讲座 | 360 | 90 段完整讲座及对应题目 |
| 本机五套 ETS 模考听力 | 170 | 每套两个听力模块，共 34 题 |
| 合计 | 1,580 | 全部逐题检查，非抽样替代 |

实际重写 1,421 道：原创 1,251 道（听答 351、对话 300、通知 240、学术讲座 360），本地模考 170 道。另有 159 道听答题经逐题复核，已有关键意思和四个选项的理由，保留原解析及审阅记录。复核中也纠正了 L82 把“昨天还笔”混同为“寻找笔”、L917 把“不必询问用户布局”误写成“布局无需改”等具体误读。

沿用三行格式：`读懂：`解释所问内容和关键英语，`解析：`用完整中文连接原话与正确项，并逐项说明另外三个选项的问题，`下次：`给出可执行的判断步骤。保留已经讲清的内容，针对压缩、遗漏或只有结论的地方补充推理。解析指向选项内容，不写死可被打乱的选项字母。

听答题会区分直接答复、间接说明、相关追问和建议：正确回应可以提供新的信息，不以“原话未提”一概排除。材料题则核对人物、时间、动作、否定、条件、因果及结论的适用范围。仅出现相同词语、场景或真实背景，不自动成为当前问题的答案。

截图中的 L367 已明确说明：这里的 sample 是抽取的一部分学生，representative 是有代表性。把下午班的学生也纳入，可改善所选学生不能反映全班情况的问题；透明容器误把调查样本理解成实物，放大字号不改变选了哪些学生，介绍上课地点也没有解决代表性问题。

## 题目自身的限制

原创 L894 的“核实晚间入场获批”可以理解为去检查许可，不能一律曲解成提前宣布已经批准。L896 的“获准两间，所以放弃一间”也可得到只使用一间的结果；旧解析把它误写成否定只用一间的方案。新解析指出参考项为何最自然，同时承认另一项有可成立的读法。保留原题与键，使旧答卷也能显示这份纠正说明，不通过改题或改分掩盖歧义。

本地模考 `ets-test-4-listening-1-10` 保留原卷参考键。男子担心修车费用和工期，支持“希望问题不严重”的推断；但“需要用车办重要的事”也有接母亲的明确文本依据。新解析说明这两个选项存在重合，区分不够严，不把有依据的选项硬说成原文没提过，也不暗改原卷评分。

模考说明仍是本地编写的学习笔记，不是 ETS 官方解析。此次依据本机已导入的完整脚本、题干、选项和参考键核对，未更换原卷或重新导入。

## 源稿与历史记录

原创内容编辑于 `question_bank/sources/receptive_items.py`、`expanded_listening.py` 及两轮扩充目录内的四种听力 JSON，随后由现有生成器重建答案和审阅目录。仅对实际修订的条目更新审阅日期、依据及指纹。模考仅修改本机 `sources/mock_explanations/ets-test-*.json` 中的听力条目和对应指纹，不分发官方原题或其本地补充文件。

题号、脚本、题干、选项、正确键、难度和考点按本轮开始时的逐题哈希核对。已有成绩、答卷、录音不写回；题面和参考答案仍匹配的旧记录，沿用现有只读机制显示新解析。

题库在服务进程内缓存。更新完成后，从托盘“退出服务”再重新启动工作台即可载入新解析；只刷新网页不会重新载入题库。验证使用独立服务和数据目录，保留原有运行服务。

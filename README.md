# TOEFL Prep Studio

**面向 TOEFL iBT 2026 的本地练习、模考与复盘工作台。**

**简体中文** · [English](README.en.md)

TOEFL Prep Studio 将阅读、听力、写作和口语整合到一个桌面浏览器应用中，支持从单题型训练到四科综合测验，再到保存答卷、回听录音和复盘解析。应用运行在个人 Windows 电脑上，题目材料为英文，界面与学习解析以中文为主。

[项目亮点](#项目亮点) · [练习模式](#练习模式) · [题库覆盖](#题库覆盖) · [快速开始](#快速开始) · [使用须知](#使用须知) · [文档](#文档)

## 项目亮点

- **完整的训练流程**：按题型或科目练习，也可完成固定模考和分级综合测验；抽题保留完整文章、对话与访谈材料。
- **围绕证据的学习解析**：按材料对照原题、作答与参考答案，以「读懂／解析／下次」说明关键线索、解题依据和可复用的方法。
- **听说练习与回放**：合成提示音支持多种英语口音和对话角色配音，口语支持麦克风录音、回放与文字转写。
- **保存在本机的复盘记录**：归档题面、答案、反馈、用时和已上传录音，支持分类与日期筛选；模考和综合测验可恢复已保存进度。

## 练习模式

| 模式 | 适用目标 | 实现方式 |
| --- | --- | --- |
| **专项练习** | 集中训练一种题型 | 自选题量与计时方式，随机抽取完整材料；同轮不重复，已提交材料降低后续抽中权重。 |
| **整科练习** | 练习单科节奏与完成度 | 使用固定单科题组，按科目限时完成，提交后统一复盘。 |
| **模拟考** | 按完整流程练习公开试卷 | 本地导入有权使用的 ETS Practice Test 1–5 后可用，每套 97 题；公开源码不附带官方材料。 |
| **综合测验** | 在不同难度下练习四科 | 从原创题库随机组成 120 题，提供五套方案和 1–10 档起始难度；阅读、听力分别在模块间调整选材。 |

专项练习中，阅读、听力和写作支持正计时与倒计时，口语使用倒计时。阅读补词直接在原文内填写；造句通过词块点击、拖动和撤回完成。

## 题库覆盖

原创练习库包含 **2,115 道计分小题、12 种题型**。ETS 模考试卷独立存放，不参与原创练习的抽题。

| 科目 | 题型 | 原创题数 | 整科题数 |
| --- | --- | ---: | ---: |
| 阅读 | 补词、日常生活阅读、学术文章 | 795 | 50 |
| 听力 | 应答、对话、公告、学术讲座 | 705 | 47 |
| 写作 | 造句、邮件、学术讨论 | 450 | 12 |
| 口语 | 听后复述、模拟访谈 | 165 | 11 |

题面与答案键分开存放，评分在服务端完成。内容来源、审阅规则和生成流程见[题库维护文档](question_bank/README.md)。

## 快速开始

需要 **Windows、Python 3.10+ 和桌面浏览器**。首次安装依赖需要联网，口语录音需要浏览器麦克风权限。

### 一键启动

双击项目根目录中的 **[TOEFL Prep Studio.cmd](<TOEFL Prep Studio.cmd>)**。启动器会准备 Python 环境，并在服务就绪后自动打开 [http://127.0.0.1:38761](http://127.0.0.1:38761/)；已有练习服务运行时直接打开页面。

### 命令行启动

在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts/launch.py
```

后续启动只需执行最后一行。日常使用无需 Node.js 或前端构建。

首次下载源码即可使用原创练习和综合测验。未导入官方试卷时，模拟考入口显示导入提示；可选的本地导入流程见[题库维护](question_bank/README.md#模考导入与隔离)。

练习时保留服务窗口，关闭窗口会停止服务；只关闭网页不会。界面面向 2560×1440 桌面屏幕及 125%／150% Windows 显示缩放，建议最大化浏览器窗口。

环境配置、测试和故障排查入口见[开发与验证](docs/technical/development.md)。

## 使用须知

**页面导航。** 页面有独立路径，例如 `/practice/reading`、`/history`、`/tests`，支持浏览器返回与前进。已归档复盘、模考和综合测验会话可直接打开或刷新恢复；路径与恢复边界见[导航说明](docs/technical/architecture.md#页面路径与浏览器导航)。

**进度与数据。** 普通练习提交成功后归档；当前标签页内返回、前进可保留当前轮次，未提交内容在刷新后丢失并回到设置或首页。模考和综合测验只在整卷结束后开放答案与复盘，已开始的计时不会因离开或刷新而暂停、重置。记录默认保存在本机 `artifacts/`，可通过 `TOEFL_DATA_DIR` 指定位置；数据管理与恢复见[存储说明](docs/technical/architecture.md#存储与归档)。

**音频依赖。** 提示音优先通过联网语音服务生成，失败时尝试匹配的浏览器音色；模考音频由试卷脚本合成。语音识别取决于浏览器支持，可手动输入或修正转写。录音上传失败时，应在离开页面前重试保存。

**评分与考试边界。** 普通练习提供原始分与文字反馈，开放题采用启发式规则。模考和综合测验仅汇总客观题正确数，开放写作与口语待人工复核。难度分级、模块路由及部分限时属于本地训练设置；应用不提供官方成绩预测，也不评估发音、语调或流利度。模考学习解析由本项目编写。
